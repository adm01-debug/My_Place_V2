# Regras escritas à mão

O que está aqui é texto humano e vive na `main`: decisões de negócio, exceções e combinações que o
código não revela. O gerador (`scripts/regras_negocio/generate.py`) copia esta pasta para
`docs/contexto/regras/manual/` na branch `contexto` sem alterar nada, e cita o conteúdo em
`07-REGRAS-DE-NEGOCIO.md`.

Um arquivo por tema (`ponto.md`, `ferias.md`, `holerites.md`…). Nada de segredo.
